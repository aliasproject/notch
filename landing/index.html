Status bar integration

Your running timer, in your shell bar

kairon status prints the currently-running timer (or nothing, if idle) and exits — no daemon required. Works with waybar, tmux, i3blocks, dwm, or anything that shells out and reads stdout.

⏱ Build feature · 1:23:45
kairon status # plain text — for shell bars kairon status -json # JSON — for waybar
// waybar config "custom/kairon": { "exec": "kairon status -json", "return-type": "json", "interval": 5 }
Theming

Matches your terminal, not the other way around

Drop a theme.conf in your config directory to recolor Kairon — built for pywal, Omarchy, and other distro-theming setups. Changes are picked up live, no restart needed.

primary = #7C3AED accent = #06B6D4 success = #10B981 warning = #F59E0B danger = #EF4444 bg = #0F172A
